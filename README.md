# Pong (old)

Simple project to learn the basics of Windows programming and GDI.

## Compile and Run

The code is written as a Visual Studio solution.

Alternatively, note the following for compilation:

 * Subsystem Windows
 * Link with core Windows libraries:
   * kernel32.lib
   * user32.lib
   * gdi32.lib
  
The final EXE-application requires advapi32.dll to run.
